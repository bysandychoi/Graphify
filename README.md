# Graphify

<img width="1536" height="1024" alt="image" src="https://github.com/user-attachments/assets/ccbb1cf3-dccc-4f42-8474-913d3e061a82" />

제조 스케줄링/그래프 실험에 쓰는 원본 현장 데이터를, **원본의 lot–설비–
resource 관계와 분포를 보존한 채로** 실험에 쓸 만한 작은 데이터로
줄여 주는 도구다. 무작위로 새 데이터를 만들어내는 대신, 원본에서 lot을
골라내고(선택) 그 lot과 연결된 데이터만 함께 축소한다.

**결과물은 원본 입력 형식 그대로의 축소 데이터다.** 초기에는 별도
그래프 입력을 만드는 것이 목표였으나, 인터뷰를 통해 "그래프 스키마로
변환"이 아니라 "원본 형식을 유지한 채로 관계를 보존해 축소"하는 쪽으로
방향을 바꿨다(problem.md 4절 53행) — 프로젝트 이름(Graphify)과 달리
새로운 그래프 파일 형식을 만들어 주는 도구가 아니다. 또한 후보를 자동
확정하지 않는다: 원본과 축소 후보의 차이를 비교표로 먼저 보여주고,
**사용자가 후보를 선택한 뒤에만** 최종 축소 데이터와 ID 대응표를
만든다(problem.md 6절).

과거에는 원본 관계를 참조하지 않고 무작위로 데이터를 생성했고, 코드
오류로 특정 resource가 모든 설비에서 가능한 것처럼 표현되어 잘못된
데이터로 학습이 진행된 적이 있다. 이 도구가 풀려는 핵심 문제는 단순한
데이터 생성이 아니라 **축소 데이터가 원본의 무엇을 보존하고 무엇을
잃었는지 눈에 보이게 확인하는 것**이다. 자세한 배경과 업무 결정은
`problem.md`에 있다.

## 1차 범위

- lot–설비–resource의 할당 가능 관계 분석 및 보존.
- lot 위치·설비 층과 그 관계 보존.
- 원본 분포 분석, 표본 후보 생성, 원본 대비 전체 비교표 제공.
- 선택한 lot을 따라간 연관 데이터 축소와 일관된 ID 변경.
- 원본 ID와 변경 ID의 대응표 생성.

## 제외 범위

- GNN 학습, RL, Scheduler 개발, 성능 최적화.
- 별도 그래프 스키마 또는 특정 학습 프레임워크 전용 입력 생성.
- 현재 확인한 범위를 넘어서는 관계의 임의 추가.
- 회사 원본 데이터의 외부 반출(problem.md 2절 — 개발·검증은 가상
  데이터로 하고, 실제 데이터 테스트는 사용자가 회사 환경에서 직접
  수행한다).

위 1차 범위/제외 범위는 problem.md 4절의 목표 문장과 포함/제외 목록을
그대로 옮긴 요약이다. 세부 근거는 그쪽을 참고한다.

## 실행 방법

**구체적인 실행 커맨드·인터페이스·결과 파일 구성은 미정이다.** 아직
생성기·축소 로직 구현이 시작 전이라 확정할 수 없다(config 구조·실행
인터페이스·결과 파일 구성은 `backlog.json`의 T077, 아직 결정 필요
상태). 실제 환경의 OS, 사용 가능한 런타임, 패키지 설치 제한, 코드
반입 방법과 접근 시점도 미확인이다(problem.md 9절).

확정된 것은 사용자가 겪을 흐름(problem.md 6절)이다:

1. 입력 데이터와 설정을 읽고 관계·위치·층 연결 정보를 확인한다.
2. 원본의 관계·속성 분포를 분석한다.
3. 목표 lot 수에 맞춘 후보와, 분포를 더 가깝게 맞추려 lot 수를 늘린
   후보를 함께 제안한다.
4. 요약보다 전체 비교표를 먼저 보여준다.
5. 사용자가 후보를 선택한 뒤에만 최종 축소 데이터와 ID 대응표를
   만든다.

개발은 Claude로, 실제 회사 환경 실행은 Codex로 진행하며, 2026-09-21까지
실제 환경에서 1차 실행·검증하는 것이 목표다(problem.md 9절).
