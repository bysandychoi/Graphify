- 예상 소요: 30분

- 참고 problem.md: 3절

## 설명

공정·step별 resource-설비 가능 관계 전체 사양을 표현하는 가상 스키마를 정의한다.

## 완료 기준

- 동일 step에서 서로 다른 resource가 서로 다른 설비 집합을 가질 수 있음을 표현 가능

## 쉬운 설명

T007은 공정·step별 자원(resource)-설비(eqp) 할당 가능 관계를 표현하는 가상 스키마를 정의하는 작업입니다.

구체적으로는:
1. eqp_step 스키마 정의 — 각 step에서 어떤 자원이 어떤 설비들과 연결되는지를 명시합니다. 예를 들어 S01 step에서 R01은 M01·M02에서 가능하지만, R02는 M03에서만 가능할 수 있습니다.
2. run_spec 스키마 정의 — 전체 사양 정보를 담습니다.

핵심은 '동일 step에서 서로 다른 resource가 서로 다른 설비 집합을 가질 수 있음'을 명확하게 표현할 수 있는 구조로 설계하는 것입니다. 이는 lot_data의 가능 쌍과 함께, 축소 로직이 원본 관계를 충분히 보존했는지 검증하는 기초가 됩니다.

가상 스키마이므로 회사 실제 데이터 구조와는 다름을 명시하고, 현재 미확인된 항목(조인 키, 연결 방식 등)도 문서에 명확히 표기해야 합니다.
