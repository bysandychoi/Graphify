# T010 가상 스키마 vs 회사 스키마 구분 문서화

- 단계: P1 (가상 스키마 정의 (회사 스키마와 구분))
- 상태: todo (할 일 (미착수))
- 예상 소요: 15분
- 선행 작업: T006, T007, T008, T009
- 참고 problem.md: 2절, 8절

## 설명

가상 스키마가 개발/검증용이며 회사 데이터 구조와 무관함을 문서에 명시한다.

## 완료 기준

- 가상 스키마 문서 상단에 구분 문구 포함

## 쉬운 설명

T010은 T006-T009에서 생성한 4개의 가상 스키마 문서(lot_data, eqp_step_run_spec, resource_data, location_floor)가 모두 개발·검증용 가상 스키마이며 회사의 실제 데이터 구조와 무관함을 명시적으로 구분하는 작업입니다.

각 문서의 상단에는 이미 '**이 문서는 개발·검증용 가상 스키마이며 회사 실제 데이터 구조가 아니다.**'라는 구분 문구와 함께, 실제 필드/키/값 체계가 미확인임을 명시하고 있습니다. 이러한 구분 문구는:
- problem.md 2절의 '회사 데이터는 외부로 반출할 수 없으므로 외부 개발·검증에는 가상 데이터를 사용'한다는 원칙과 
- problem.md 8절의 '가상 데이터용 스키마와 기대 결과는 실제 회사 스키마와 구분해 기록한다'는 요구사항을 
구현하는 것입니다.

완료 기준 '가상 스키마 문서 상단에 구분 문구 포함'을 확인하고, 각 문서가 일관되게 이 원칙을 따르고 있음을 검증하는 것이 이 작업의 범위입니다.
