# T012 설비·resource 마스터 생성 로직

- 단계: P2 (가상 데이터 생성기)
- 상태: in_progress (작업중)
- 예상 소요: 30분
- 선행 작업: T011
- 참고 problem.md: 8절

## 설명

설비 80대, resource 24개, 설비별 층 배정을 생성한다.

## 완료 기준

- 설비 id/층, resource id가 중복 없이 생성됨

## 쉬운 설명

T012는 가상 제조 데이터 생성 프로젝트의 설비·리소스 마스터를 생성하는 작업입니다.

구체적으로:

1. **생성 대상:**
   - 설비(eqp): config에서 지정된 수만큼 생성(기본값 80대). 각 설비에 고유한 ID와 층 번호를 부여합니다.
   - 리소스(resource): config에서 지정된 수만큼 생성(기본값 24개). 각 리소스에 고유한 ID를 부여합니다.
   - 층 정보: config의 floor_count로 지정된 층 수 범위 내에서 각 설비에 층 번호를 배정합니다.

2. **생성 결과 (출력 데이터):**
   - eqp_floor: 각 설비의 ID와 층 정보를 담은 테이블
   - resource_data: 각 리소스의 ID(및 선택적 속성)을 담은 테이블

3. **완료 기준:**
   - 설비 ID/층, 리소스 ID가 모두 중복 없이 생성됨
   - 생성된 설비/리소스 수가 config 지정값과 일치함
   - 각 설비의 층 번호가 1 이상 floor_count 이하의 유효한 범위 내에 있음
