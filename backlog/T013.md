# T013 eqp_step 가능 쌍 생성 로직

- 단계: P2 (가상 데이터 생성기)
- 상태: in_progress (작업중)
- 예상 소요: 30분
- 선행 작업: T012
- 참고 problem.md: 3절, 8절

## 설명

공정·step별로 resource가 가능한 설비 집합을 생성한다 (동일 step 내 resource별로 다른 설비 집합 허용).

## 완료 기준

- 같은 step에서 resource별 가능 설비 집합이 다르게 생성될 수 있음

## 쉬운 설명

공정과 step의 각 조합별로, 그 단계에서 필요한 자원들과 각 자원별 가능한 설비 집합을 정의하는 eqp_step 데이터를 생성한다. T012가 생성한 설비 마스터(eqp_floor, resources)를 받아, config의 process_count/step_count로 모든 공정-step 조합을 만든다. 각 조합마다 여러 자원 행을 생성하되, 같은 step 내에서도 자원별로 다른 설비 집합이 가능해야 한다(예: S01에서 R01은 M01/M02, R02는 M03만 가능). 생성된 eqp_step은 이후 단계에서 lot의 가능 쌍 검증과 불일치 감지의 기준 사양으로 사용된다.

## 관련 파일

- `generator/master.py` — T012 산출물(eqp_floor, resources)을 입력받는 기반
- `docs/generator/config.md` — scale.process_count/step_count 정의 및 유효 lot 수 개념
- `docs/virtual_schema/eqp_step_run_spec.md` — 생성할 eqp_step 스키마(process/step/resource/eligible_eqp_ids 필드)
- `docs/virtual_schema/lot_data.md` — candidate_pairs 스키마로 생성 데이터의 검증 기준
