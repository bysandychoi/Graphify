# T001 저장소 문서 구조 설계

- 단계: P0 (저장소 최소 하네스)
- 상태: todo (할 일 (미착수))
- 예상 소요: 30분
- 선행 작업: 없음
- 참고 problem.md: 9절

## 설명

README/AGENTS/CLAUDE/HANDOFF의 역할 분담과 최소 하네스 구조를 정의한다. 공통 규칙은 AGENTS.md에 모으고 CLAUDE.md는 이를 참조하도록 한다.

## 완료 기준

- 4개 문서의 역할과 목차가 정해짐
- AGENTS.md가 공통 규칙의 단일 출처임이 명시됨

## 쉬운 설명

Graphify 프로젝트를 새로운 개발자나 실행 환경(Codex)에 인수인계할 수 있도록, README/AGENTS/CLAUDE/HANDOFF 4개 문서의 역할과 목차를 정의하는 작업. 현재 AGENTS.md와 CLAUDE.md는 작성돼 있으나 README는 거의 비어있고 HANDOFF는 미작성 상태. 각 문서의 목적, 포함할 섹션, 상호 참조 관계를 명시해서 어느 문서를 먼저 읽어야 하는지, 공통 규칙의 단일 출처가 무엇인지 명확히 한다.

## 관련 파일

- `AGENTS.md` — 공통 규칙 단일 출처, 이미 작성됨
- `CLAUDE.md` — AGENTS.md를 참조하는 가이드, 이미 작성됨
- `README.md` — 프로젝트 개요 (거의 비어있음)
- `problem.md` — 9절에서 문서화와 인수인계 요구사항 정의

## 비고

코드/문서만으로 인수인계 가능해야 함(9절).
