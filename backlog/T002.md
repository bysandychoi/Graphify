## 쉬운 설명

Graphify 프로젝트의 README.md를 작성해서 다음을 담아야 합니다:

**프로젝트 목적**: 제조 스케줄링 데이터를 작은 데이터로 줄이되, 원본의 관계와 분포를 보존하는 도구

**포함 기능 범위**:
- lot-설비-resource의 할당 가능 관계 분석
- lot 위치·설비 층과 그 관계 분석
- 원본 분포 분석, 표본 후보 생성, 전체 비교표 제시
- 연결된 데이터 축소와 ID 일관성 변경
- 원본 ↔ 변경 ID 대응표 생성

**제외 범위**:
- GNN 학습, RL, Scheduler 개발, 성능 최적화
- 별도 그래프 스키마 또는 학습 프레임워크 전용 입력 생성
- 현재 범위를 넘어서는 관계의 임의 추가
- 회사 원본 데이터의 외부 반출

**실행 개요**:
