# T015 설비 수 분포 다양화 로직

- 단계: P2 (가상 데이터 생성기)
- 상태: done (완료)
- 예상 소요: 30분
- 선행 작업: T014
- 참고 problem.md: 8절

## 설명

lot별 가능 설비 수가 1~N까지 다양하게 분포하도록 생성 파라미터를 조정한다.

## 완료 기준

- 생성 데이터에서 설비 수별 lot 개수 히스토그램이 다양함

## 쉬운 설명

각 lot을 생성할 때 설비 수(eligible_eqp_count) 분포를 지정된 비율대로 맞추는 작업입니다.

**현재 상황:**
T014(lot_data 가능 쌍 생성)에서는 각 lot의 current_step을 무작위로 선택하고, 그 step에 해당하는 candidate_pairs를 만듭니다. 이 결과 eligible_eqp_count(할당 가능 설비 수)는 균형 없이 분포됩니다.

**T015가 해야 할 일:**
- config의 `case_ratios.eligible_eqp_count_distribution`에서 읽은 분포(예: {"1": 0.2, "2": 0.6, "3": 0.2})에 따라
- 생성할 lot_count개 중에서 각 eligible_eqp_count별 lot 개수를 결정하고
- 각 lot마다 원하는 설비 수를 만족하는 candidate_pairs가 되도록 조정하기

**구체 예시:**
- 10,000개 lot을 생성하되
- 설비 수 1개인 lot: 2,000개 (20%)
- 설비 수 2개인 lot: 6,000개 (60%)
- 설비 수 3개인 lot: 2,000개 (20%)
이렇게 분포되도록 생성

**주의:**
- 설비 수 0인 lot(candidate_pairs가 빈 배열)도 가능 (config에 "0" 키 포함 시)
- 키 값은 scale.eqp_count(전체 설비 수) 이하여야 함
- 이전 T013·T014 산출물 구조를 활용해서 구현

**완료 기준:**
생성된 데이터의 설비 수별 히스토그램이 config 분포를 따름

## 관련 파일
