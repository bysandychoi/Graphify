# T014 lot_data 가능 쌍 생성 로직

- 단계: P2 (가상 데이터 생성기)
- 상태: in_progress (작업중)
- 예상 소요: 30분
- 선행 작업: T013
- 참고 problem.md: 3절

## 설명

eqp_step을 참고해 lot별 (eqp, resource) 가능 쌍을 생성한다. 설비 수는 쌍의 중복 없는 eqp 집합 크기로 계산한다.

## 완료 기준

- 설비 수가 eqp 집합 크기와 항상 일치
- (M01,R01),(M02,R02) 존재 시 (M01,R02)가 암시되지 않음

## 쉬운 설명

각 lot마다 현재 처리할 step에서 사용 가능한 (설비, resource) 쌍들을 만드는 작업입니다.

**구체적으로 뭘 하나요?**
1. config에서 생성할 lot 수를 받습니다
2. 각 lot마다:
   - 처리할 step을 정합니다 (S01, S02 등)
   - T013이 생성한 eqp_step에서 해당 (공정, step, resource) 행들을 찾습니다
   - 각 행의 eligible_eqp_ids(가능 설비 목록)와 resource를 조합해 (설비, resource) 쌍을 만듭니다
   - 이 쌍들을 lot의 candidate_pairs에 넣습니다
3. 각 lot마다 candidate_pairs에 나타나는 중복 없는 설비의 개수를 eligible_eqp_count로 계산합니다
   - (M01,R01), (M01,R02) → eligible_eqp_count = 1 (M01만)
   - (M01,R01), (M02,R02) → eligible_eqp_count = 2 (M01, M02)

**주의할 점:**
- 명시된 쌍만 만듭니다. (M01,R01), (M02,R02)가 있어도 (M01,R02)를 자동으로 만들면 안 됩니다
- candidate_pairs의 중복 여부와 정렬은 구현 시 정의합니다

**완료 기준:**
- eligible_eqp_count가 candidate_pairs의 중복 없는 eqp 개수와 항상 일치
- 암시된 쌍이 없음
