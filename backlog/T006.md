# T006 가상 lot_data 스키마 정의

- 단계: P1 (가상 스키마 정의 (회사 스키마와 구분))
- 상태: in_progress (작업중)
- 예상 소요: 30분
- 선행 작업: 없음
- 참고 problem.md: 3절, 8절

## 설명

lot id, 현재 step, 가능 (eqp, resource) 쌍 목록, 선택 속성(설비 수 계산용 포함) 필드를 가상 스키마로 정의한다. 회사 실제 필드가 아님을 명시한다.

## 완료 기준

- 가능 쌍이 (eqp,resource) 튜플 목록으로 표현됨
- 설비 수는 별도 저장하지 않고 쌍에서 계산 가능함을 명시

## 쉬운 설명

T006은 가상 lot_data의 필드 구조를 정의하는 작업입니다.

lot 데이터에 포함되어야 할 필드를 명시적으로 정의해야 합니다:
- lot id: 각 lot을 구분하는 고유 ID
- 현재 step: lot이 현재 진행할 단계
- 가능 (eqp, resource) 쌍 목록: 이 step에서 할당 가능한 (설비, 자원) 쌍들을 튜플 형식으로 저장 (예: [(M01, R01), (M02, R02)])
- 선택 속성: 분포 분석용 추가 필드 (예: 우선순위 등 - 실제 필드는 회사에서 아직 확인 안 됨)

특히 중요한 점은 '설비 수'라는 필드를 따로 저장하지 말고, 가능 쌍 목록에서 중복 없는 eqp 개수를 계산으로 얻을 수 있도록 설계한다는 것입니다. 예를 들어 쌍이 [(M01, R01), (M01, R02)]라면 설비 수는 1입니다.

목표는 '회사 실제 데이터와 구분되는 가상 스키마'를 문서로 명시하는 것입니다.
