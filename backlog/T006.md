# T006 가상 lot_data 스키마 정의

- 단계: P1 (가상 스키마 정의 (회사 스키마와 구분))
- 상태: todo (할 일 (미착수))
- 예상 소요: 30분
- 선행 작업: 없음
- 참고 problem.md: 3절, 8절

## 설명

lot id, 현재 step, 가능 (eqp, resource) 쌍 목록, 선택 속성(설비 수 계산용 포함) 필드를 가상 스키마로 정의한다. 회사 실제 필드가 아님을 명시한다.

## 완료 기준

- 가능 쌍이 (eqp,resource) 튜플 목록으로 표현됨
- 설비 수는 별도 저장하지 않고 쌍에서 계산 가능함을 명시
